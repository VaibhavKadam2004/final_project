# 🚀 QUICK START - OPEN JOBS IN 30 SECONDS

## 🎯 The Fastest Way

### **3 Steps:**

```
1. Go to: http://127.0.0.1:8000/admin/
   
2. Login: admin / Admin@123
   
3. Click → "Job posts" → Select All → "Open selected jobs" → Go
```

✅ **DONE!** All jobs are now open for student applications.

---

## 📊 What Each Status Means

```
🟢 OPEN      = Students can see & apply
🔴 CLOSED    = Hidden from students
⏰ DEADLINE   = Must be future date for job to show
```

## ✨ Two Ways to Open Jobs

### **Option A: Bulk (ALL jobs at once)**
```
1. ☑️ Select All checkbox (top-left)
2. 📍 Action dropdown → "Open selected jobs"
3. ✅ Click "Go" button
```

### **Option B: Individual (One job)**
```
1. 👆 Click job title
2. 📋 Find "Status" dropdown
3. 📝 Change "Closed" → "Open"
4. 💾 Click "SAVE" button
```
