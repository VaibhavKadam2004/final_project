## 🔐 Authentication

When you run `git push`, you'll be asked to authenticate. Choose one:

### Option A: Browser Authentication (Easiest)
- Browser opens automatically
- You log in to GitHub
- Click "Authorize"
- Done!

### Option B: Personal Access Token
1. Go to: https://github.com/settings/tokens
2. Generate new token (classic)
3. Select: `repo` and `workflow`
4. Copy token
5. Paste when Git asks for password

### Option C: SSH Key
- Set up SSH key on GitHub (more advanced)
- Use SSH URL instead of HTTPS
