📋 REQUIREMENTS
════════════════════════════════════════════════════════════════════════════

✅ GitHub account (free at github.com)
✅ Git installed
✅ Your project folder
✅ Internet connection


🎯 3-STEP PROCESS
════════════════════════════════════════════════════════════════════════════

STEP 1: Create Repository on GitHub
─────────────────────────────────────

Go to: https://github.com/new

Fill the form:
  • Repository name: placement-portal
  • Visibility: Public
  • Leave Initialize options UNCHECKED

Click: Create repository

Copy the URL shown (looks like):
  https://github.com/YOUR_USERNAME/placement-portal.git


STEP 2: Update Git Remote
──────────────────────────

Open PowerShell in your project folder

Run these commands:

  git remote remove origin

  git remote add origin https://github.com/YOUR_USERNAME/placement-portal.git

Replace YOUR_USERNAME with your actual GitHub username!

Example:
  git remote add origin https://github.com/VaibhavKadam2004/placement-portal.git


STEP 3: Push to GitHub
───────────────────────

Run this command:

  git push -u origin main

When prompted, authenticate with GitHub:
  • Use browser pop-up (easiest), OR
  • Enter Personal Access Token (get from github.com/settings/tokens)

Done! ✨

❌ COMMON ERRORS & SOLUTIONS
════════════════════════════════════════════════════════════════════════════

Error: "Repository not found"
→ Check: Username spelling in URL
→ Check: Repository created on GitHub
→ Check: No typos in the command

Error: "Authentication failed"
→ Use: Personal Access Token (not password)
→ Get token: https://github.com/settings/tokens
→ Select scopes: repo, workflow
→ Paste token when asked

Error: "Permission denied"
→ Verify: You created the repository
→ Check: Correct GitHub account logged in
→ Try: Personal Access Token authentication
