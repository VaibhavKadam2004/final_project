## 🆘 Troubleshooting

### Problem: Can't see the sidebar
**Solution:**
- Make sure you're logged in
- Check the left edge of your screen
- On mobile, click the ☰ menu icon

### Problem: Sidebar disappeared on mobile
**Solution:**
- Click the ☰ menu icon to bring it back
- Or just scroll left

### Problem: Links in menu don't work
**Solution:**
- Hard refresh: `Ctrl+F5`
- Clear cookies: `Ctrl+Shift+Delete`
- Try logging out and logging back in

### Problem: Don't see "Advanced Features"
**Solution:**
- Make sure you're logged in as student
- If you're admin/recruiter, different features show
- Refresh the page: `F5`
